# Dataset contracts and sources

The default T7–T15 data are generated in `her_core/analytics.py:example_data` with seed 42. They contain no actual patient records. No external download is needed for the submission demonstration. They are intentionally small: 180 operational days, 36 clinical-style texts, and 180 adult observations. All displayed results are computed at runtime.

T1–T6 use the existing `BraTS2020/` directory: eight local case folders, six with FLAIR and segmentation. These files and the existing partial archive were preserved. The project has no authoritative provenance manifest for the previously supplied scans; do not infer patient demographics or clinical validation from their folder names. MRI access via API is restricted to this folder. Removing it produces an explicit unavailable-data response.

| Tutorials | Required CSV fields | Units / validation | Target |
|---|---|---|---|
| T7–T9 | date, admissions | Parseable date and nonnegative numeric admissions. Optional department; optional occupied_beds and capacity must be supplied together, capacity >0 and occupied≤capacity; optional nonnegative cost in one consistently documented currency. No missing values in supplied operational fields. | Admissions forecast / operational summaries |
| T10 | text, label | At least 12 distinct normalized texts, ≥2 classes, ≥3 per class; conflicting duplicate labels rejected. | label |
| T11–T12 | text | Nonempty strings, max 20,000 characters each. T11 analyzes entered text or the first document. T12 ranks the corpus and disambiguates entered context. | Mentions / relevance / supported MS and RA senses |
| T13–T15 | age, height_m, weight_kg, activity_hours_week, sedentary_hours_day, sleep_hours | Age in years; height meters; weight kg; activity hours/week; sedentary and sleep hours/day. Only known ages ≥18. At least 20 adults; supported measurement ranges enforced. Missing behavioral values may be imputed in exploratory/model pipelines; unknown height/weight never creates a BMI target. | PCA/Isomap, descriptive BMI, held-out BMI regression |

T7 requires ≥30 consecutive distinct daily observations; it does not reinterpret monthly observations as days. T8–T9 accept other date frequencies: the T9 trend uses actual elapsed calendar days, while admissions retain the source period's units. Operational costs and occupancy are calculated only when supplied. IQR outlier flags do not automatically remove adults. Repeated measurements are not modeled as independent patients in a validated clinical study.

Upload UTF-8 `.csv` files, at most 2 MB, 5,000 rows, 50 columns. The UI sends the raw file body with `Content-Type: text/csv` to `/api/tutorials/{id}/upload`; this is deliberately not a multipart form endpoint. Files are parsed in memory and never saved. Errors report required columns or malformed values. Notebook users can call `tutorial_dataset(id, csv_path='your.csv')`; an absent file raises a readable FileNotFoundError. Do not commit sensitive records.

To obtain a reproducible example CSV, click **Download labeled synthetic example CSV** or open `/api/tutorials/7/example` (replace 7 with T7–T15). Re-uploading a CSV labels it “user-supplied, provenance not independently verified”; this is not a claim that uploaded data are real patient observations. Preserve the downloaded SYNTHETIC filename when demonstrating it.

Optional external data preparation:

1. **Operations:** download a public workbook from [NHS England A&E Attendances and Emergency Admissions](https://www.england.nhs.uk/statistics/statistical-work-areas/ae-waiting-times-and-activity/). Select one consistent count definition, a period and provider group; export a small CSV with `date`, `admissions`, and optionally provider mapped to `department`. Monthly public tables can demonstrate T8/T9 summaries, with frequency caveats above. They cannot run the daily T7 forecast directly. Do not invent daily counts, bed capacities or costs absent from the source.
2. **Clinical text:** the optional [MIMIC-IV-Note source](https://physionet.org/content/mimic-iv-note/2.2/) requires credentialed access and a data-use agreement. Follow its access steps independently; this app neither downloads nor bypasses access. Export only an authorized small `text` corpus and approved classification labels for T10. T11/T12 need no label column. The included synthetic corpus avoids this access requirement.
3. **Adult research:** obtain public participant measurements and questionnaires through [CDC NHANES](https://wwwn.cdc.gov/nchs/nhanes/). Select one survey cycle and join compatible components by participant identifier. Use its codebooks to map age, measured height and weight and actually available behaviors; convert centimeters to meters and minutes to hours. For example, the [2017–March 2020 physical-activity codebook](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/P_PAQ.htm) documents sedentary minutes. Explicitly recode refused/unknown questionnaire codes as missing, derive weekly hours only from compatible duration/frequency questions, and never relabel a frequency score as hours. Export the six-column contract above. This manual preparation was not exercised because no such files were supplied. The app's unweighted educational analyses are not population-weighted NHANES inference.

No additional clinical NLP model is required: entity extraction and abbreviation interpretation use explicit, limited rules documented in the module and notebook. Mention counts and lexical relevance are not clinical accuracy measurements.
